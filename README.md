# redis-from-scratch

A Redis clone built from scratch in Rust, implementing the RESP protocol and core in-memory data structures/commands from the ground up.


**Primary language:** Rust

## Project structure

Top-level files in this repository:

- `Cargo.lock`
- `Cargo.toml`
- `docs`
- `src`
